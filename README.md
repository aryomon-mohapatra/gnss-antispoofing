# gnss-antispoofing
ML-driven GNSS spoofing detection using hybrid LSTM Autoencoder + XGBoost ensemble. Extracts 18 signal features (C/N₀, Doppler, pseudorange residuals) for real-time detection — 97% recall, &lt;2% false alarm rate, &lt;15ms latency. IIT Bombay Kaizen × ARIES × NyneOS · March 2026.
